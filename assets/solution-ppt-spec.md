# 解决方案 PPT 编撰与排版规范（solution-ppt-spec）

> 供「方案 Markdown → 解决方案 PPT」转换与 PPT 编撰时参考。适用于售前宣讲、方案汇报、评审答辩等演示场景；PPT 与方案文档内容同源（先出 Markdown 方案，再转 PPT），保证口径一致。

## 一、适用判断

| 场景 | 推荐形态 |
|------|----------|
| 售前宣讲 / 客户汇报 | PPT（16:9）+ 演讲备注 |
| 评审答辩 | PPT + 演讲备注（备注写足论证要点） |
| 正式归档 / 报送 | 公文格式 .docx（见 `official-docx-format.md`） |
| 内部流转 | Markdown |

## 二、页面结构（由方案 13 个一级标题自动映射）

| 页面类型 | 来源 | 说明 |
|----------|------|------|
| 封面页 | `# 方案标题` + 元信息 | 标题 + 副标题（项目背景一句话）+ 落款 |
| 目录页 | 11 章标题 | 分两栏列出章节 |
| 章节过渡页 | 每个 `## 章节` | 章节号 + 章节名 + 本章小节清单 |
| 内容页 | 每个 `### 小节` | 小节标题 + 要点 bullet（≤6 条）+ 可选表格 |
| 结尾页 | — | 致谢 + 下一步行动 |

> 章节过渡页与内容页交替：先"章节页"点题，再逐小节"内容页"展开，形成清晰的宣讲节奏。

## 三、版式与配色

| 项目 | 规范 |
|------|------|
| 画幅 | 16:9（13.333×7.5 英寸）；如需投屏兼容可 4:3 |
| 主色 | 深蓝（标题/强调）+ 中蓝（装饰条） |
| 正文 | 深灰，白底，浅蓝底用于章节过渡页 |
| 标题字号 | 封面 40pt / 章节页 34pt / 内容页 24pt |
| 正文字号 | 16pt，每页要点 ≤6 条 |
| 字体 | 微软雅黑（中文） |
| 表格 | 表头深蓝底白字，正文 11pt |

## 四、演讲备注规范（每页必写）

演讲备注是 PPT 的"隐形讲稿"，放映时用「演示者视图」查看。每页备注须含四要素：

1. **【本页主题】**：一句话点明该页讲什么
2. **【讲解要点】**：把该页 bullet 展开成 1-2 句口语化讲解
3. **【数据/依据】**：如本页有表格/指标，提示"强调第 X 行数据"
4. **【过渡】**：承上启下的过渡句

> 备注原则：口语化、短句、不照念 PPT 原文；封面讲"开场白+一句话背景"，结尾讲"总结+下一步行动"。

## 五、转换方法

### 路径 A：转换脚本（推荐）
```bash
python3 md2solution_ppt.py 方案.md -o 方案.pptx --author 某公司 --ratio 16:9
```
- 自动生成封面/目录/章节页/内容页/结尾页，并逐页写入演讲备注
- 若无脚本，用 python-pptx 按上表版式手工生成；关键点：中文字体须设 `a:ea typeface`，否则 PPT 不生效

### 路径 B：手动编撰
按「二、页面结构」组织页面，每页要点 ≤6 条、字号按「三、版式」，逐页补「四、演讲备注」。

## 六、转换后自查清单（交付前）

1. **页数合理**：封面 + 目录 + 章节页 + 内容页 + 结尾，无空白页
2. **每页有备注**：演讲备注四要素齐全（主题/要点/依据/过渡）
3. **要点不超载**：每页 ≤6 条 bullet，超出的拆分
4. **表格清晰**：表头深蓝底、正文 11pt，列数 ≤6 列（过多拆分）
5. **口径一致**：PPT 数据/结论与 Markdown 方案源一致，不出现源方案没有的指标
6. **脱敏**：机构名、金额、案例一律脱敏（同 `SKILL.md` AP-07）

## 七、常见问题

| 问题 | 处理 |
|------|------|
| 中文显示为默认字体 | 转换时设 `a:ea typeface`（微软雅黑）；打开后全选统一字体 |
| 章节过渡页无内容页（该章无 ### 小节） | 该章内容并入章节页 bullet，或把正文段提炼为要点 |
| 表格列太多挤不下 | 拆分表格或精简列，列数 ≤6 |
| 需要页脚页码/公司 logo | 在母版（Slide Master）统一加，脚本默认不加 |
| 需要更精细的演讲备注 | 脚本生成结构化备注后，可人工润色为口语化讲稿 |

## 八、合规提醒

- PPT 同样遵守脱敏红线（AP-07），不得出现真实客户名/精确金额
- AI 相关页须标注"AI 仅辅助、最终由医师审核"（同 `ai-applications.md` 监管红线）
- 对外宣讲 PPT 建议封面落款"编制单位 + 日期"，页脚加"内部资料/脱敏示意"
