# 投资估算量化参考库

> 售前/咨询最常被审计问到"大概要花多少钱"。本库提供**量级示意区间**（非真实报价），供方案编撰时给出"投资量级参照框架"，避免给出无依据的精确数字，也避免完全空白。所有金额均为**脱敏示意**，实际须以立项批复、招标控制价或正式询价为准。

---

## 一、使用原则

1. **只给量级，不给精确价**：以区间形式呈现（如"约 800–2000 万元"），并明确为示意
2. **标注口径**：区分"软件许可 / 硬件 / 集成实施 / 数据治理 / 等保密评 / 培训运维"
3. **随规模浮动**：同样的系统，三级医院与二级医院、单院与区域，量级可差数倍
4. **不写死未来价**：人力与软件单价逐年变化，编撰时建议 WebSearch 核验近期市场区间
5. **脱敏**：方案中出现的"某项目投资额"一律用"脱敏示意，以立项批复为准"

## 二、分场景投资量级示意（人民币，含软硬件与实施）

| 场景 | 核心建设内容 | 量级示意区间 | 说明 |
|------|-------------|-------------|------|
| 互联互通四级甲等 | 集成平台 + EMPI + 共享文档生成器 + 接口改造 + 测评服务 | 800–2000 万 | 取决于存量系统数量与改造量 |
| 电子病历 5 级 | EMR 升级 + CDR + CDSS（规则引擎） + 数据治理 + 模拟测评 | 1000–3000 万 | 老 EMR 重构成本占比高 |
| 智慧医院三位一体 | 智慧医疗+服务+管理 三大评估配套 + 数据中台 | 2000–5000 万 | 三甲综合目标 |
| 县域医共体数智一体 | 区域平台 + AI 中台 + 运营驾驶舱 + 基层 SaaS 接入 | 2000–5000 万 | 含县乡村三级 |
| 县域医共体基础版 | 信息平台 + 协同应用 + 轻量 HIS | 800–2000 万 | 基础打通 |
| 城市医疗集团 | 集团平台 + 网格化 + 远程协同 + 医防融合 | 3000–8000 万 | 多三级协同，复杂度高 |
| 中心药房 | 采购+处方流转+追溯+自动发药 | 300–800 万 | 视成员单位数量 |
| 云审方中心 | 审方引擎 + 规则库 + 药师工作站 | 200–600 万 | 可依托既有平台 |
| 连锁民营（集团） | 多租户云平台 + 会员/营销中台 + 专科系统 | 500–2000 万/集团 | 按分院数扩展 |
| 三级以下单体（基层） | SaaS 化核心系统 + 公卫融合 | 50–200 万 | 轻量化、年服务费模式 |

> 以上为**整体项目量级示意**，非单系统报价；实际受区域、既有基础、招标模式影响极大。

## 三、投资构成拆分（占比示意）

一个典型医院信息化项目，投资构成大致如下（示意，非固定比例）：

| 构成 | 占比示意 | 内容 |
|------|---------|------|
| 软件许可/订阅 | 35–50% | 平台、业务系统、AI 组件、第三方中间件 |
| 硬件/基础设施 | 15–25% | 服务器、存储、网络、安全设备、终端 |
| 集成实施 | 15–25% | 接口改造、部署、联调、数据迁移 |
| 数据治理 | 5–10% | 主数据、字典、质量整改 |
| 等保密评 | 3–6% | 测评、整改、国密改造 |
| 培训与运维（首年） | 5–10% | 培训、驻场、质保 |

## 四、方案中的写法示例

> **投资估算（脱敏示意）**：本项目整体投资量级约 **1200–1800 万元**，其中软件平台约 600 万、硬件基础设施约 300 万、集成实施与数据治理约 350 万、等保密评与培训约 150 万。具体金额以立项批复与招标控制价为准，本方案不构成报价承诺。

> 风险提示：投资估算不含因政策变更（如信创改造范围扩大）带来的增量成本，实施阶段须据实调整。

---

## 五、常见审计追问与应答要点

- **"为什么这么贵/这么便宜？"** → 回到构成拆分，说明口径与浮动因素
- **"和同类医院比呢？"** → 说明规模/存量/目标差异，避免直接对比
- **"能否分期？"** → 对应实施路径，给出分期投资节奏（先底座后应用）
- **"含运维吗？"** → 明确首年质保与后续运维费用边界
