# 智慧中药房专项知识库

> 面向中医院、中西医结合医院、综合医院中医科、基层中医馆及医共体共享中药房的方案编撰参考。覆盖处方流转、智能审方、自动调剂、煎煮配送、质量控制、药事服务全链路。

---

## 一、业务定义与适用场景

| 类型 | 定义 | 典型适用对象 |
|------|------|-------------|
| **院内智慧中药房** | 医院内部中药房自动化改造：智能审方、自动调剂、煎药中心、配方颗粒调剂 | 三级/二级中医院、综合医院中医科 |
| **医共体/区域共享中药房** | 以牵头医院为中心，向乡镇卫生院、社区中医馆、民营中医机构提供审方、调剂、煎煮、配送服务 | 县域医共体、城市医疗集团 |
| **互联网+中药房** | 承接互联网医院、线上复诊的中药处方流转与配送 | 互联网医院、DTP 药房、第三方中药服务平台 |

## 三、核心业务模块

### 1. 处方流转与采集

- **处方来源**：HIS/EMR 中医科、互联网医院、基层中医馆、医共体成员单位
- **处方类型**：饮片处方、配方颗粒处方、中成药处方、协定处方、膏方
- **处方上传**：标准化字段（患者信息、诊断、证型、饮片/颗粒明细、剂量、剂数、煎法、服法）
- **电子签名**：符合《电子签名法》与医疗电子签名规范

### 2. 智能审方（中药专用）

| 审方维度 | 典型规则 |
|---------|---------|
| 配伍禁忌 | 十八反、十九畏、妊娠禁忌 |
| 剂量超限 | 单味药剂量超《中国药典》/地方炮制规范 |
| 特殊人群 | 儿童、老人、孕妇、肝肾功能不全剂量调整 |
| 毒性药管理 | 附子、半夏、细辛等毒性/麻醉药品限量与先煎/久煎提示 |
| 证型用药 | 寒热虚实错配、中西药相互作用 |
| 医保规则 | 中药饮片/颗粒限定支付、诊断与药品匹配 |

- **审方流程**：系统自动预审 → 药师复审 → 风险处方沟通确认 → 放行/驳回
- **知识库**：《中国药典》《中药大辞典》《临床用药须知》、医院协定处方库、名医经验方库

### 3. 自动调剂系统

- **饮片自动调剂**：多工位智能药柜 + 机械臂/转盘称量 + 条码复核
- **配方颗粒智能调配**：单剂量颗粒智能识别、自动称重、自动封装
- **复核机制**：视觉复核（拍照留痕）+ 重量复核 + 条码复核
- **调剂精度**：误差一般要求 ≤±5%（医院自定 ±3% 更优）

### 4. 煎药中心

| 环节 | 关键能力 |
|------|---------|
| 处方接收 | 自动分配煎煮任务，按剂数、煎法（先煎/后下/包煎/烊化）分组 |
| 浸泡 | 定时浸泡，记录水温与时间 |
| 煎煮 | 自动控温、控时、控压；支持常压煎、高压煎、浓缩 |
| 包装 | 自动灌装、贴签（患者信息、处方号、服用说明、有效期） |
| 质检 | 煎药记录全程留痕；抽检外观、装量、微生物 |
| 配送 | 院内窗口自取、病区配送、快递冷链、医共体成员单位配送 |

### 5. 药品追溯与库存管理

- 中药饮片/颗粒批号、产地、质检报告、养护记录全链路追溯
- 库存预警：效期预警、安全库存预警、特殊药品（毒性/麻醉）专库管理
- 对接国家药品追溯码平台（中药饮片逐步推进一物一码）

### 6. 药事服务与患者触达

- 用药指导：煎服方法、禁忌、储存、复诊提醒
- 患者查询：煎药进度、物流跟踪、用药提醒
- 不良反应（ADR）上报：中药专项 ADR 采集与分析

## 五、关键指标

| 维度 | 指标 | 参考目标 |
|------|------|---------|
| 效率 | 平均每方调剂时间 | ≤8 分钟（自动调剂） |
| 效率 | 煎药日产能 | 按煎药机数量，单台 60–120 剂/日 |
| 质量 | 调剂差错率 | ≤0.1% |
| 质量 | 审方拦截率 | ≥5%（预警+拦截合计） |
| 质量 | 患者投诉率 | ≤0.5% |
| 服务 | 处方流转覆盖率 | 医共体内成员单位 ≥90% |
| 合规 | 煎药记录可追溯率 | 100% |

## 六、方案撰写要点

1. **明确建设模式**：院内改造 / 区域共享 / 互联网+中药房，三种模式投资、运营、合规差异大
2. **突出中医药特色**：审方规则、煎煮工艺、证型管理、协定处方库是西医药房方案不具备的
3. **合规前置**：毒性药、麻醉中药、妊娠禁忌、煎药室 GMP 式管理必须单独成章
4. **区域共享须明确权责**：审方责任主体、药品质量责任、配送破损责任、医保结算归属
5. **与 SPD 的衔接**：中药饮片/颗粒是否纳入 SPD 统一管理，需在方案中明确边界

## 七、常见风险与应对

| 风险 | 应对 |
|------|------|
| 中药饮片规格/产地差异大，自动调剂精度难保证 | 建立院内饮片质量标准，优先选择规格稳定的品种上自动调剂 |
| 先煎/后下等特殊煎法多，自动化难度大 | 采用柔性煎煮线，支持多锅并行与工艺参数模板化 |
| 区域共享中药房跨机构医保结算复杂 | 明确牵头医院为医保结算主体，成员单位按协议分成 |
| 患者对代煎药质量不信任 | 全程可视化（拍照/视频）、煎药记录扫码可查、开放窗口参观 |
| 中药审方知识库维护工作量大 | 与中医药大学/中医院合作，建立院级/区域级知识库共建机制 |
