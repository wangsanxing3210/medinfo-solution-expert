# SPD（医疗耗材供应链管理）专项知识库

> 面向医院、医共体、医疗集团的医用耗材、试剂、药品供应链精细化管理方案。覆盖 SPD 定义、运营模式、核心模块、院内物流、高值耗材追溯、合规廉政风险与方案撰写要点。

---

## 一、SPD 定义与价值

**SPD（Supply Processing Distribution）** 即"供应-加工-配送"，是一种由第三方服务商或医院自建团队对医用物资（耗材、试剂、部分药品）进行集中采购、院内物流管理、科室消耗结算的供应链管理模式。

| 价值维度 | 说明 |
|---------|------|
| 降本 | 通过集中采购、院内物流优化、降低库存资金占用 |
| 合规 | 全程追溯、杜绝"跑冒滴漏"、防范商业贿赂风险 |
| 提效 | 科室零库存/二级库管理，护士站扫码消耗，减少盘点工作量 |
| 控费 | 按病种/DRG/DIP 维度分析耗材使用，支撑医保控费 |
| 质量 | 效期预警、冷链监控、高值耗材一物一码全程追溯 |

## 二、政策与标准依据

- 《医疗器械监督管理条例》（国务院令第 739 号）
- 《医疗机构医用耗材管理办法（试行）》（国卫医发〔2019〕43 号）
- 《医疗器械使用质量监督管理办法》（国家食药监总局令第 18 号）
- 《高值医用耗材集中采购工作规范》
- 《关于治理高值医用耗材的改革方案》（国办发〔2019〕37 号）
- 国家医保局医用耗材统一编码规则（医保医用耗材分类与代码）
- 等保 2.0、数据安全法、个人信息保护法
- 各地卫健委 SPD 管理规范/试点文件（以项目所在地最新文件为准）

## 三、SPD 运营模式

| 模式 | 说明 | 适用对象 |
|------|------|---------|
| **院外库模式** | 供应商将物资存放在医院外仓库，按需配送至院内 | 大型医院、物资周转快 |
| **院内库模式** | 医院提供场地，SPD 服务商管理院内中心库与二级库 | 多数三级医院 |
| **消耗后结算模式** | 物资在科室扫码消耗后才与供应商结算，医院零库存 | 高值耗材、试剂 |
| **第三方 SPD 服务** | 医院引入第三方服务商承担运营，医院保留采购决策权 | 降本压力大、IT 力量弱 |
| **医院自建 SPD** | 医院自行建设 SPD 系统与运营团队 | 集团化医院、管理能力强 |

**关键原则**：
- 医院不能因 SPD 外包而转移医疗器械使用质量责任
- 采购权、定价权、供应商选择权必须归医院所有，SPD 服务商只负责"物流+信息"
- 高值耗材必须实现"一物一码"全程追溯

## 四、核心模块

### 1. 供应商管理

- 供应商准入：资质证照、授权链、信用评级
- 订单协同：采购计划 → 供应商确认 → 发货 → 到货验收
- 绩效评估：供货及时率、缺货率、退换货响应、价格竞争力

### 2. 采购与供应计划

- 基于科室消耗数据的需求预测
- 安全库存、再订货点（ROP）、经济订货批量（EOQ）
- 集采目录、限价管理、协议价管理

### 3. 入库与验收

- 到货扫码验收（UDI / 院内码 / 医保码）
- 冷链验收（温度记录、冷链设备对接）
- 质检报告、注册证、效期录入

### 4. 院内中心库与二级库

| 库类型 | 定位 | 管理方式 |
|--------|------|---------|
| 中心库 | 医院物资总仓 | 按科室需求拆包、分拨、配送 |
| 科室二级库 | 病区/手术室/介入室耗材存放点 | 定数包、扫码消耗、补货触发 |
| 智能柜 | 高值耗材/贵重药品专用 | 指纹/人脸识别、一物一码、自动盘点 |
| 术间套包 | 手术耗材按术式预配置 | 按手术排程推送、术间扫码核销 |

### 5. 高值耗材全程追溯

- **一物一码**：最小销售单元条码、批次、序列号、效期
- **流程闭环**：采购 → 入库 → 科室领用 → 患者使用（扫码绑定患者）→ 计费 → 结算
- **关键场景**：介入耗材、骨科植入物、人工晶体、起搏器等
- **监管对接**：国家药监局 UDI 数据库、医保局耗材编码平台

### 6. 低值耗材与试剂管理

- 定数包管理：按科室常用量打包，消耗后自动补货
- 试剂管理：批号、效期、开瓶效期、质控品对接 LIS
- 不可收费耗材：成本分摊到科室/病种

### 7. 消耗与结算

- 扫码消耗：护士站/手术室扫码后实时扣库存、触发补货
- 消耗后结算：月底按实际消耗与供应商对账结算
- 科室成本核算：按 DRG/DIP 病种分析耗材成本
- 财务对账：SPD 系统 → HRP/财务系统 → 供应商付款

### 8. 冷链与效期管理

- 冷链设备 IoT 监控：冰箱、冷柜、冷藏车温度实时采集
- 效期预警：近效期 30/60/90 天自动预警
- 效期先进先出（FEFO）策略

## 六、关键指标

| 维度 | 指标 | 参考目标 |
|------|------|---------|
| 效率 | 科室请领响应时间 | ≤2 小时（常规耗材） |
| 库存 | 库存周转天数 | 高值耗材 ≤7 天；低值耗材 ≤30 天 |
| 合规 | 高值耗材一物一码追溯率 | 100% |
| 合规 | 效期过期事件 | 0 起 |
| 成本 | 耗材占比下降 | 试点科室 5%–15%（视基础而定） |
| 质量 | 配送差错率 | ≤0.2% |
| 财务 | 月度对账差异率 | ≤0.5% |

## 七、合规与廉政风险

| 风险点 | 防控措施 |
|--------|---------|
| 采购权外包 | 明确医院保留采购权、定价权、供应商选择权；SPD 只负责物流与信息 |
| 商业贿赂 | 建立供应商黑名单、异常采购预警、关键岗位轮岗 |
| 高值耗材套标/串换 | UDI 一物一码、扫码计费、患者绑定、异常用量预警 |
| 效期管理失控 | 系统自动预警、近效期强制下架、FEFO 策略 |
| 数据安全 | 耗材价格、供应商信息加密；权限分级；操作留痕 |
| 医疗器械质量责任 | 医院仍是第一责任人；SPD 服务商资质审查、合同明确质量条款 |

## 八、方案撰写要点

1. **先明确运营模式**：第三方 SPD / 医院自建 / 混合；采购权、库存权、结算权如何划分
2. **高值耗材单列一章**：UDI 追溯、一物一码、患者绑定是监管重点
3. **与 HIS/HRP/财务的集成**：消耗数据如何进入科室成本、如何对账结算
4. **科室二级库设计**：哪些科室先上、定数包如何设计、补货触发机制
5. **冷链与效期**：试剂、生物制品必须写清楚
6. **廉政合规**：不是可选章节，必须有供应商管理、异常预警、审计留痕
7. **投资与回报**：降本测算模型（库存资金占用下降、采购成本下降、人力成本变化）

## 九、与智慧中药房/中心药房的关系

| 系统 | 管理对象 | 与 SPD 边界 |
|------|---------|------------|
| SPD | 医用耗材、试剂、部分高值药品 | 以物资供应链管理为核心 |
| 中心药房 | 西药、中成药、部分口服药 | 以处方流转和药学服务为核心 |
| 智慧中药房 | 中药饮片、配方颗粒、膏方 | 以中医药特色审方、调剂、煎煮为核心 |

**建议写法**：方案中明确"西药/中成药纳入中心药房/SPD 统一管理，中药饮片/配方颗粒纳入智慧中药房管理"，避免三者边界模糊。
