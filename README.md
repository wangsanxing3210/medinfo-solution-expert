# 医疗信息化解决方案专家 · medinfo-solution-expert

> 一个面向医疗信息化行业的解决方案 **编撰 · 审核 · 优化 · 招投标应答 · 选型对比** 全生命周期专家级 Agent Skill。
> 兼容 OpenClaw、WorkBuddy 等支持 SKILL.md 规范的 Agent 框架，内置标准规范库、覆盖 31 类系统的核心系统知识库、19 大项目场景库、AI 医疗应用场景库、数据安全与数据要素库、中医 AI 库、政策时效性核验台账与方案审核清单，
> 输出符合国内医疗信息化标准的结构化 Markdown 方案文档，可按需转换为公文格式 .docx 或演示 PPT（含逐页演讲备注）。

---

## ✨ 这个 Skill 能做什么

| 能力 | 说明 |
|------|------|
| **方案编撰** | 基于医院场景需求，自动生成结构完整、术语规范、政策符合的解决方案文档 |
| **方案审核** | 逐项审核已有方案，指出逻辑漏洞、政策不符、技术可行性问题并给出修改建议 |
| **方案优化** | 从架构、业务流程、数据流、技术选型维度润色，提升说服力与可落地性 |
| **方案自检 / 预评分** | 编撰后自动（或按需）跑一遍审核清单，输出加权预评分、等第与问题清单，快速判定"能否提交" |
| **数据安全合规** | 按数据分类分级（核心/重要/一般、"就高不就低"）、等保定级对齐、全生命周期管控、日志留存、个人信息保护等要求成章落地（2026 年起为一票否决项） |
| **中医 AI 合规** | 中医 AI 产品二类/三类分类界定、注册路径、四诊设备边界、使用场景资质红线（避免"AI 自动辨证开方"类合规硬伤） |
| **政策时效核验** | 内置政策时效性台账，每条政策登记**核验日期**；超 1 个季度即强制复核，回答"这条政策还有效吗""现在该引哪一版" |
| **演示输出（PPT / 公文 docx）** | 方案可一键转**演示 PPT**（16:9、封面/目录/章节页/内容页/结尾，**逐页自动生成演讲备注**）或**公文格式 .docx**（GB/T 9704-2012 简化版，带导航目录） |
| **使用指引（开箱即用）** | 内置「30 秒快速开始」「能力边界与异常处理（ERR-01~ERR-11）」「62 条常见问题 FAQ」「反模式速查（AP-01~AP-12）」「复杂场景拆解」「多轮对话示例」，降低上手门槛与歧义处理成本 |

无论是投标前的方案突击、售前评审的查漏补缺，还是日常方案的二次打磨，一句话就能调用。

### 🚀 快速 4 步上手

1. **选场景**：在「适用场景」里找到你的项目类型（19 大场景编号 1~19）
2. **下需求**：一句话描述项目背景（如「某县人民医院互联互通四级甲等建设方案」），未说清的关键字段技能会按「澄清问卷」主动追问
3. **拿方案**：技能自动按 13 个一级标题（文档摘要+目录+11 章）输出 Markdown 方案，末尾自动跑一遍预评分自检
4. **改打磨**：可让技能审核/优化已生成方案，或基于同一方案继续多轮迭代（每轮异常会输出 ERR/AP 码便于诊断）

## 🧭 设计原则

- **CDSS 双引擎**：规则引擎为主、LLM 为辅，规避大模型幻觉风险
- **AI 融入三要素**：必要性 + 可行性 + 风险可控，避免无脑堆 AI
- **数据安全可核验**：按数据分类分级定保护措施与等保级别（重要数据三级及以上、核心数据非关基四级），不做"等保三级一句带过"
- **政策时效是机制不是记性**：所有政策登记核验日期，超 1 个季度强制复核；"写过"不等于"仍然准确"
- **不确定就写成核验动作**：信源冲突时（如中医 AI 三类证获批情况）不选边断言，而是写明"须在 NMPA 数据库核验后据实表述"
- **等保 2.0 三级底线**：核心业务系统安全合规不可省略（并叠加上述数据分级要求）

## ⚠️ 安全与伦理

本 Skill 仅提供方法论、标准规范与方案框架参考，**不处理任何真实患者诊疗数据、个人隐私数据或未经脱敏的机构数据**。所有示例均以脱敏样例数据呈现；真实项目须遵守《数据安全法》《个人信息保护法》《医疗卫生机构数据安全和个人信息保护管理办法（试行）》（国卫规划发〔2026〕6 号）、《医疗卫生机构网络安全管理办法》（国卫规划发〔2022〕29 号）及人类遗传资源相关法规。涉及 AI 医疗应用（含中医 AI）的方案须明确医疗器械注册、伦理审查与人工兜底要求；本技能**不出具医疗器械注册申报材料，也不断言注册证获批情况**（须以国家药监局官方查询结果为准）。
